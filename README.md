# FurgoTrans – Landing page (Next.js 15, App Router, JavaScript, Tailwind CSS v4)

```bash
npm install
npm run dev     # http://localhost:3000
```

- Textos y datos: `src/data/content.ts`
- Colores: tokens en `@theme` de `src/app/globals.css` (navy, brand, soft)
- Imagen del hero: `public/images/hero-truck.png`
- Formulario: conecta `onSubmit` en `src/components/Contact.tsx` a tu API o servicio de email
